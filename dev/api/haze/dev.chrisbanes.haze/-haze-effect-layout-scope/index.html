HazeEffectLayoutScope

interface HazeEffectLayoutScope : Density

Semantic layer-layout scope for a custom Haze effect.

modifierBounds is initially aligned to the modifier. Bounds returned by HazeEffectRenderer.calculateLayerBounds define the required effect layer around it.
