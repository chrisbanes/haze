HazeEffectRuntimeDrawScope

interface HazeEffectRuntimeDrawScope : HazeEffectDrawScope

Built-in-only semantic draw capability.

Source geometry and layers remain owned by core. Built-ins can record the selected input into their own target DrawScope without receiving source handles.
